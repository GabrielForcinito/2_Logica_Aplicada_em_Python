## 🎯 Funcionalidades

* Resolução de problemas matemáticos

* Aplicação de lógica básica
* Processamento de dados numéricos

---

## 📝 Desafios propostos

1. Calcular salário com acréscimo de 5% de comissão
2. Calcular velocidade média (distância / tempo)
3. Converter dólar para real
4. Calcular valor total com 10% de gorjeta
5. Converter temperatura de Celsius para Fahrenheit e Kelvin

---

## 💻 Como executar

1. Clone ou baixe este repositório
2. Abra o projeto no **Visual Studio Code**
3. Abra o terminal integrado
4. Execute o arquivo Python com o comando:

```bash
python nome_do_arquivo.py
```

> 💡 Substitua `nome_do_arquivo.py` pelo arquivo que deseja executar.
> 💡 Recomenda-se a execução pelo terminal do VS Code para melhor visualização e interação com o programa.
